# ECHO — 소리로 보는 던전

화면은 암흑입니다. 소나 펄스를 쏘면 음파가 닿은 벽만 잠깐 드러났다가 사라지고, 그 소리는 적도 부릅니다. 절차 생성 던전 10층을 탈출하는 스텔스 로그라이크.

**플레이:** https://echo-sonar.web.app/

## 컨셉

- **소리로 본다.** `Space`/클릭으로 펄스를 쏘면 링이 퍼지며 벽이 드러납니다. 적·아이템·열쇠·출구도 링이 지나가는 순간 블립으로 표시됩니다.
- **소리는 적을 부른다.** 펄스, 발소리, 돌멩이, 조명탄은 모두 소음 이벤트입니다. 사냥꾼은 소리를 따라 조사하고, 가까우면 추격합니다. `Shift`로 살금살금 걸으면 거의 소리가 나지 않습니다.
- **적도 소리를 낸다.** 적의 발소리는 파문으로 보입니다. 심장 소리가 빨라지면 가까이 있다는 뜻. 박쥐는 자기 소나를 쏴서 벽을 공짜로 보여 주지만 사냥꾼도 함께 부릅니다. 거미는 조용히 기다리고, 포식자(5층부터)는 큰 소리에 깨어납니다.
- **층마다 다른 던전.** 방+통로+동굴 혼합 생성, 3층부터 열쇠로 출구를 열어야 합니다. 10층 탈출 후 무한 모드로 더 내려갈 수 있습니다.
- **오늘의 던전.** 날짜 시드로 모두가 같은 던전을 탐험합니다.
- **랭킹.** 최고 층 · 최단 탈출 · 오늘의 던전 랭킹(Firebase Firestore, 닉네임 등록).
- 아이템: 돌멩이(유인), 조명탄(넓게 오래 밝힘, 매우 시끄러움), 소음기(12초 정숙), 붕대. 층 도달 해금 6종. 모든 사운드는 Web Audio로 합성됩니다.

## 조작

| 동작 | 키 |
|---|---|
| 이동 | `W A S D` / 방향키 · 터치: 왼쪽 조이스틱 |
| 살금살금 | `Shift` · 터치: 조이스틱을 살짝, 또는 살금 버튼 |
| 소나 펄스 | `Space` / 마우스 왼쪽 · 터치: 펄스 버튼 |
| 돌멩이 던지기 | `1` / 마우스 오른쪽 (마우스 방향) |
| 조명탄 · 소음기 · 붕대 | `2` · `3` · `4` |
| 일시정지 | `Esc` |
| 디버그 오버레이 | `F3` |

## 개발

```bash
npm install
npm run dev       # http://localhost:5174
npm test          # vitest 33개 (던전 연결성, 레이캐스트, A*, 충돌, 저장 등)
npm run build     # tsc --noEmit + vite build → dist/
npm run deploy    # 빌드 후 Firebase Hosting(echo-sonar) 배포
```

프레임워크 없이 TypeScript + Canvas 2D. `src/world/`·`src/core/`는 DOM에 의존하지 않는 순수 로직이며, 던전 생성은 `(시드, 층)`에 대해 결정적입니다. 튜닝 수치는 `src/config.ts`에 있습니다.
